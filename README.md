# Firebreak

Firebreak: a response to the "Flame in Freefall" challenge (NASA Space Apps 2026). A dashboard that summarizes, ranks and interprets NASA PSI microgravity combustion investigations. Pick a habitat (ISS, Moon Base, rover) and see which investigations apply, with cited evidence.

```
npm install
npm run dev
npm run gate
```

Lane ownership and rules: [LANES.md](LANES.md).
